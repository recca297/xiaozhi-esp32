# Default Theme (Theme ID 0)

This is the default built-in emoji set for XiaoZhi AI firmware.
It utilizes vector / font glyphs from Noto Emoji (`noto_emoji.h`) and Material Symbols (`material_symbols.h`).

## Features
- Dynamic text font rendering on LCD/OLED screens via LVGL.
- Ultra lightweight: zero additional flash image overhead.
- Supports all 21 standard XiaoZhi emotions.
